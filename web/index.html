执行流

            
每个 agent 一行：当前状态、最近输出、工具/ token 用量。被阻塞的会标红并显示在等谁。

          

          

            
工具瀑布

            
按耗时排序的调用。红条斜纹 = 失败；点上方颜色图例可只看某类工具。

          

          

            
时间轴

            
拖拽框选一段放大，滚轮以光标为锚点缩放，双击复位。斜纹是空闲区间。

          

          

            
事件与快捷键

            
? 看全部快捷键，T 切换主题；右侧事件列表可搜索、↑↓ 选择。

          

        

        

          这些提示随时可以在 ? 里重新查看
          
        

      

    


    

      

        

          快捷键与手势
          
        

        

          

            
键盘

            

              
Space
播放 / 暂停

              
← →
后退 / 前进 1 秒（按住 Shift 为 5 秒）

              
↑ ↓
在事件列表中移动

              
Enter
打开选中项详情

              
+ -
以播放头为锚点缩放时间窗

              
0
时间窗复位到全量

              
Home End
跳到开头 / 结尾

              
Esc
关闭帮助或详情

              
?
打开本页

              
T
切换主题（跟随系统 / 深色 / 浅色）

              
/
聚焦搜索框（Esc 清空并退出）

              
⌘K / Ctrl K
快速切换会话

              
P
收藏 / 取消收藏当前会话

              
F
焦点跟随：跳过空闲 + 自动滚动高亮当前焦点

            

          

          

            
鼠标 / 触控板

            

              
时间轴滚轮
以光标为锚点缩放（对着哪放大哪）

              
时间轴拖拽
框选一段区间，主视图切过去

              
Shift + 拖拽
平移时间窗

              
双击时间轴
复位到全量

              
瀑布 / 事件行
点击跳到该时刻并打开详情

              
工具图例
点击只看该类工具调用（再点取消）

            

          

          

            
地址参数（可分享）

            

              
?file=
指定会话文件

              
?t=
定位到某一时刻（毫秒）

              
?from=&to=
时间窗（毫秒）

              
?embed=1
嵌入模式（插件面板用，隐藏自身顶栏）
